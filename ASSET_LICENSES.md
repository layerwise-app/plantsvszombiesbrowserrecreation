   README states personal Python-learning practice, personal learning and research only, and no other uses. No conventional permissive code or asset license was found. Their original game rights are not granted by the README. Graphics with animation frame filenames have their black color key converted to transparency; a logo mask is composited locally.
3. https://github.com/FregD156/PvZ_Assets
   README describes extraction from the original macOS `main.pak`. No LICENSE or redistribution permission was found. `public/pvz/original` contains selected local scene, menu, and interface resources. These are proprietary original-game assets, not permissively licensed resources. The repository targets macOS, so it does not establish perfect PC 2009 asset parity.

The source repositories were downloaded locally for inspection. Reference license/readme snapshots and commit IDs are retained in `references/`. They are provenance records, not a statement that the assets may be redistributed.
